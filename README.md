# PROFESSIONAL DEVELOPER PORTFOLIO
## Project Specification & Development Instructions

Build a modern, professional personal portfolio website for a fresh graduate developer with approximately 2+ years of hands-on experience through independent projects.

The portfolio owner is a:

**Software Engineer & Machine Learning Engineer**

with additional focus on:

- Artificial Intelligence
- Machine Learning
- Natural Language Processing
- MLOps
- Web Development
- Backend Development
- Software Engineering

The portfolio must NOT look like a generic student portfolio or a template.

It should feel like a professional engineer portfolio suitable for:

- Recruiters
- Hiring managers
- Software engineering companies
- AI/ML companies
- Startups
- Freelance clients
- Technical collaborators

The website should communicate:

> Although I am a fresh graduate, I have approximately 2+ years of hands-on experience building software, machine learning systems, AI applications, and web applications through independent projects.

Do NOT overemphasize the phrase "fresh graduate".

Experience should be communicated through actual projects, technical depth, engineering decisions, and measurable results.

---

# 1. PRIMARY OBJECTIVE

Create a high-quality personal portfolio that communicates:

1. Professional identity
2. Technical capabilities
3. Real project experience
4. Engineering mindset
5. Machine learning and AI capabilities
6. Software development capabilities
7. Ability to build complete systems
8. Ability to work across frontend, backend, AI/ML, and infrastructure

The portfolio should prioritize **PROJECTS and TECHNICAL WORK** rather than excessive biography.

Projects are the primary proof of experience.
